Официальное приложение Яндекс Музыки для Windows сделано на Electron: внутри браузер Chromium,
семь процессов и около 850 МБ памяти. **Яндекс Музыка RS** повторяет его интерфейс (те же
шрифты, цвета, отступы и страницы), но написана на Rust и рисует окно сама, на процессоре.
В итоге один файл на 26 МБ, один процесс и около 65 МБ памяти.

> [!IMPORTANT]
> Это неофициальный проект. Он не связан с Яндексом, и Яндекс его не поддерживает. Названия
> и товарные знаки принадлежат их владельцам. Нужен ваш аккаунт Яндекса, а для полных треков —
> подписка Плюс, как и в официальном приложении.

## Этот форк

Форк проекта [SpolzerMod/yamusic-rs](https://github.com/SpolzerMod/yamusic-rs), взят за основу
выпуск **1.0.2**. Вся исходная функциональность сохранена: интерфейс, «Моя волна», страницы
исполнителей, альбомов и плейлистов, тексты песен, замеры памяти — как в оригинале.

- версия форка: **2.0.9**, сборка r22, ветка `lionforest2.09`;
- `main` апстрима не затрагивается: форк живёт отдельной веткой от 1.0.2;
- **сборка и поддержка — только Arch Linux** (x86_64). Как поставить — [Установка (Arch Linux)](#установка-arch-linux);
- что у нас есть, а в основной ветке нет — [отдельная таблица](#чего-нет-в-основной-ветке);
- сборка из исходников: `cargo build --release` (Rust 1.92+).

Что сделано в форке:

| Что | Подробнее |
|---|---|
| Работа на Linux | сборка под Linux (X11/XWayland), пути по XDG, токен в системной связке ключей |
| Скрытие в трей и возврат окна | окно прячется в лоток и возвращается, содержимое после возврата рисуется полностью |
| Сворачивание без «моргания» | перерисовка не срабатывает в момент сворачивания: защита 1,5 с и повторная проверка |
| Скачанные треки | скачанное видно в подпапках списков и играется с диска, зелёная отметка у скачанного |
| Быстрый старт сетевых треков | заготовка следующего трека заранее и порог готовности буфера для старта |
| Полный список популярного у исполнителя | заголовок «Популярные треки» открывает отдельную страницу с поиском и постраничной загрузкой |
| Мелочи интерфейса | дизлайк, компактный режим, ввод с клавиатуры |

Основа и авторство — [SpolzerMod/yamusic-rs](https://github.com/SpolzerMod/yamusic-rs),
Copyright © 2026 Spolzer, лицензия GPL-3.0. Форк распространяется на тех же условиях,
исходный код доступен в этом репозитории.

## Чего нет в основной ветке

Форк живёт своей веткой, поэтому часть доработок есть только здесь.

**Есть в форке — нет в основном проекте (1.1.x):**

| Что | Что даёт |
| --- | --- |
| Значок в лотке на Linux (StatusNotifierItem) | KDE, GNOME с расширением, XFCE, Cinnamon: скрыть окно в трей и вернуть его, меню с управлением воспроизведением. В основной ветке трея на Linux нет вообще |
| Виджет для панели KDE Plasma 6 | отдельный плазмоид `org.rask.yamusicrs`: «Исполнитель — Трек» и play/пауза прямо на панели, попурок с prev/play/next. Лежит в [extras/kde-widget](extras/kde-widget), ставится через `kpackagetool6` |
| Окно на Wayland через X11 (XWayland) | Wayland не умеет скрывать и возвращать окно, поэтому на KDE Wayland трей без этого бесполезен. Откат на чистый Wayland: `YAMUSIC_NO_X11=1` |
| Перерисовка содержимого после возврата из трея | окно не остаётся чёрным или полупустым после сворачивания и возврата |
| Защита от «моргания» при сворачивании | перерисовка не возвращает окно на экран в момент нажатия «свернуть»: откладывается на 1,5 с и перепроверяется через 140 мс |
| Дизлайк | кнопка «не нравится» на главной и в плеере, а не только в «Моей волне» |
| Скачанные треки | играются с диска, в том числе из подпапок списков; у скачанного зелёная отметка |
| Потоковое воспроизведение | сетевой трек начинает играть, не дожидаясь полной загрузки; следующий трек готовится заранее |
| Компактный режим | узкая полоса-миниплеер с возвратом прежнего размера окна |
| Полный список популярного у исполнителя | отдельная страница вместо блока на странице исполнителя: по 100 треков, поиск по названию, воспроизведение с любого места, «Нравится» |
| Исправление «зажатого указателя» | после перетаскивания окна кнопки заголовка снова работают |

**Есть в основной ветке — у нас этого нет** (переносили не всё, чтобы не потерять Linux-доработки):

| Что | Комментарий |
| --- | --- |
| Discord Rich Presence | не переносили |
| Готовые пакеты .deb, .rpm, AppImage | мы собираем только пакет для Arch Linux |
| Смена темы на ходу без перезапуска | у нас тема применяется при запуске |
| Отдельное окно обновления приложения | обновление — установкой новой сборки вручную |

## Возможности

<img src="docs/lyrics.gif" width="100%" alt="Полноэкранный плеер RS: обложка слева, справа текст песни прокручивается вместе с треком">

- «Моя волна» с колесом вайбов и настройками «по характеру», «под настроение» и «по языку»,
  «Для вас и Тренды», «Концерты», «Книги и подкасты», чарт, поиск и коллекция.
- Страницы исполнителей, альбомов и плейлистов. Свои плейлисты можно переименовывать, менять им
  обложку и описание, удалять из них треки.
- Полноэкранный плеер с текстом песни, который идёт вместе с треком.
- Скачивание треков с обложкой и тегами ID3. По умолчанию в `Музыка\Яндекс Музыка`, папку можно
  сменить в настройках.
- Эквалайзер на 10 полос, светлая и тёмная тема, русский, английский, узбекский и казахский языки.
- Трей и автозапуск вместе с Windows. Если закрыть окно во время игры, музыка не остановится.
- Мини-плеер поверх всех окон: обложка, название и три кнопки. Включается кнопкой рядом
  с «Свернуть».
- Медиаклавиши клавиатуры работают, даже когда окно свёрнуто.
- Статус «Слушает …» в Discord и переключатель «Меньше ИИ» для рекомендаций.
- Обновление из приложения: когда выходит новая версия, сверху появляется кнопка «Обновить».
- Режим «Лёгкий» без анимаций для слабых компьютеров.

## Замеры

<img src="docs/live.gif" width="100%" alt="Графики памяти и процессора за 50 секунд. Официальное приложение держится около 800–850 МБ, RS — около 60 МБ. Процессор в среднем 2,9% против 0,4%">

Оба приложения по очереди проходят один и тот же сценарий, клики идут по таймеру:

1. запуск;

4. на 32-й — полноэкранный плеер с текстом песни.

цифры будут другими, но разница того же порядка.</sub>

## Установка (Arch Linux)

Форк собирается и проверяется только на **Arch Linux** (x86_64). Другие дистрибутивы не тестировались:
код опирается на X11/XWayland, D-Bus, StatusNotifierItem и MPRIS, и на них поведение может отличаться.

### Способ 1: пакет из PKGBUILD

```bash
git clone https://github.com/LionForestDev/yamusic-rs.git
cd yamusic-rs/packaging
makepkg -si
```

Пакет соберёт бинарник из исходников этой ветки и поставит: плеер в `/usr/bin/yamusic-rs`,
ярлык в меню, иконки в hicolor, виджет для панели KDE в `/usr/share/plasma/plasmoids`.

### Способ 2: вручную из исходников

```bash
sudo pacman -S --needed base-devel git rust alsa-lib dbus fontconfig freetype2 \
  libx11 libxcursor libxi libxkbcommon libxkbcommon-x11 libxrandr wayland

git clone -b lionforest2.09 https://github.com/LionForestDev/yamusic-rs.git
cd yamusic-rs
cargo build --release --locked

sudo install -Dm755 target/release/yamusic-rs /usr/bin/yamusic-rs
sudo install -Dm644 packaging/yamusic-rs.desktop /usr/share/applications/yamusic-rs.desktop
for size in 16 32 48 64 128 256; do
  sudo install -Dm644 "packaging/icons/${size}.png" \
    "/usr/share/icons/hicolor/${size}x${size}/apps/yamusic-rs.png"
done
```

Сборка занимает несколько минут: Skia (рендерер Slint) компилируется вместе с проектом.
Для сборки нужен интернет — cargo скачивает зависимости.

### Первый запуск

1. Запустите `yamusic-rs` из меню или терминала.
2. Войдите по коду устройства: приложение покажет код и ссылку ya.ru/device, пароль не спрашивается.
3. Токен сохраняется в системной связке ключей (KWallet или GNOME Keyring), настройки — в
   `~/.config/yamusic-rs`, кэш обложек и шрифтов — в `~/.cache/yamusic-rs`.
4. Галочка «Запускать с системой» создаёт ярлык автозапуска `~/.config/autostart/yamusic-rs.desktop`
   (это автозапуск сеанса, а не служба systemd).

### Виджет для панели KDE

```bash
kpackagetool6 --type Plasma/Applet --install extras/kde-widget     # установить
kpackagetool6 --type Plasma/Applet --upgrade extras/kde-widget     # обновить
kpackagetool6 --type Plasma/Applet --remove org.rask.yamusicrs     # удалить
```

Нужен KDE Plasma 6.0 или новее. После установки: правый клик по панели → «Добавить элементы…» →
«Яндекс Музыка RS». Подробности — [extras/kde-widget](extras/kde-widget).

### Удаление

```bash
sudo pacman -Rns yamusic-rs          # если ставили пакетом
rm -rf ~/.config/yamusic-rs ~/.cache/yamusic-rs
```

Скачанные треки лежат в `~/Музыка/Яндекс Музыка` — удаляйте по желанию.

## Установка (Windows, основной проект)

Этот раздел описывает оригинальный проект. Наш форк для Windows не собирается и не проверяется —
для Linux смотрите [Установка (Arch Linux)](#установка-arch-linux).

1. Скачайте `yamusic-rs.exe` со страницы [последнего релиза](https://github.com/SpolzerMod/yamusic-rs/releases/latest).
2. Положите файл в любую папку, например в `Документы` или `C:\Programs`, и запустите.
   Установщика нет, приложение целиком помещается в один exe.
3. Приложение покажет код. Откройте [ya.ru/device](https://ya.ru/device) на компьютере или телефоне
   и введите его. Пароль в приложение вводить не нужно.

> [!NOTE]
> У exe нет цифровой подписи, поэтому при первом запуске Windows SmartScreen может показать «Windows
> защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае». Контрольная сумма
> SHA-256 файла есть на странице релиза. Exe собирается на GitHub Actions прямо из исходников,
> лог сборки открыт. Можно собрать и самим ([как это сделать](#сборка)).

**Обновление.** Приложение раз в полчаса проверяет релизы на GitHub. Кнопка «Обновить» скачивает
новый `yamusic-rs.exe`, сверяет его SHA-256 с релизом, заменяет старый файл и перезапускается.
Если папка закрыта для записи (например, `Program Files`), кнопка откроет страницу релиза,
и файл можно заменить вручную.

**Удаление.**
1. Выключите в настройках «Запускать вместе с Windows», если включали.
2. Удалите `yamusic-rs.exe`.
3. Удалите папку `%APPDATA%\yamusic-rs` с настройками, входом и кэшем.

Скачанные треки лежат в `Музыка\Яндекс Музыка`, их удаляйте по желанию.

## Какие системы поддерживаются

| Система | Состояние |
| --- | --- |
| **Windows 11** x64 | Основная платформа, проверяется каждая версия. |
| **Windows 10** x64 | Должна работать: приложение использует те же API. Углы окна будут прямыми, потому что скругление есть только в Windows 11. Регулярно не проверяется, о проблемах пишите в [issues](https://github.com/SpolzerMod/yamusic-rs/issues). |
| Windows на ARM | Должна запускаться через эмуляцию x64. Не проверялась. |
| Windows 7 и 8.1 | Не поддерживаются: текущий Rust под них не собирает. |
| **Arch Linux** x86_64 | Сборка этого форка, проверяется на каждой версии. Установка — [Установка (Arch Linux)](#установка-arch-linux). |
| Другие дистрибутивы Linux | Не проверялись: код опирается на X11/XWayland, D-Bus и MPRIS. Может работать, гарантий нет. |
| macOS | Пока не планируется. |

**Нужно ещё:**
- аккаунт Яндекса. Без Плюса сервер отдаёт только 30-секундные отрывки;
- интернет. Офлайн-режима, как в мобильном приложении, нет;
- шрифты YS Text и иконки. Если официальное приложение установлено, RS берёт их из него.
  Если нет, один раз скачивает с music.yandex.ru в `%APPDATA%\yamusic-rs\assets`.

## Частые вопросы

<details>
<summary><b>Это безопасно? Куда уходит мой токен?</b></summary>

<br>

Вход идёт по коду устройства через ya.ru/device, пароль приложение не видит. Полученный токен
шифруется средствами Windows (DPAPI) и хранится в `%APPDATA%\yamusic-rs\config.json`. Расшифровать
его может только ваша учётная запись Windows на этом компьютере.

На Linux токен хранится не в DPAPI, а в системной связке ключей (KWallet или GNOME Keyring),
шифрованный файл настроек лежит в `~/.config/yamusic-rs`.

Токен отправляется только по https и только на домены `yandex.ru` и `yandex.net`. Проверка
встроена в код (`src/client.rs`). Кроме Яндекса приложение ходит только к `api.github.com`,
чтобы проверить обновления, и к Discord на этом же компьютере (локальный канал), если включён
статус. Аналитики и телеметрии нет.
</details>

<details>
<summary><b>Почему так мало памяти?</b></summary>

<br>

Официальное приложение — это сайт внутри Chromium: отдельные процессы для окна, страницы, GPU,
звука и расширений плюс движок JavaScript. RS — обычная программа на Rust. Интерфейс описан
на [Slint](https://slint.dev) и рисуется библиотекой [Skia](https://skia.org) на процессоре,
без видеокарты. Видеокарта сделала бы прокрутку чуть дешевле, но драйвер сразу забирает
100–150 МБ, поэтому от неё отказались. Обложки декодируются ровно под размер на экране и живут
в кэше с ограничением по объёму.
</details>

<details>
<summary><b>Чем RS отличается от официального приложения?</b></summary>

<br>

Внешне почти ничем, это видно на сравнении выше. Чего пока нет или что работает иначе:

- на «Для вас и Тренды» показываются не все блоки: например, «Подборки музыки» и «Артист рекомендует»
  пока пропускаются;
- нет выбора города для концертов и загрузки своих треков;
- нет панели управления в системном меню громкости;
- собственные настройки RS («Режим работы», «Статус в Discord», автозапуск) переведены только на русский.

Есть и то, чего нет в оригинале: режим «Лёгкий», статус в Discord, автозапуск в трее.
</details>

<details>
<summary><b>Где посмотреть, что пошло не так?</b></summary>

<br>

Ошибки пишутся в `%APPDATA%\yamusic-rs\log.txt`. API Яндекса неофициальный и может меняться без
предупреждения. Как сообщить о проблеме, написано [ниже](#как-помочь).
</details>

<details>
<summary><b>Можно запускать сразу свёрнутым? А если запустить второй раз?</b></summary>

<br>

`yamusic-rs.exe --tray` запускает приложение сразу в трее, так же работает автозапуск. Второй
запуск не открывает вторую копию, а показывает уже открытое окно.
</details>

## Как помочь

### Сообщить об ошибке

Откройте [issue](https://github.com/SpolzerMod/yamusic-rs/issues/new/choose) и напишите:

- версию RS из «Настройки → О приложении» и версию Windows;
- что вы делали, что ожидали увидеть и что получилось;
- последние строки `%APPDATA%\yamusic-rs\log.txt`, если там есть что-то про эту ошибку.

Токена в логе нет, но в адресах запросов может встретиться числовой id вашего аккаунта. Его можно
заменить на `***`. Со скриншотами то же самое: закрепы и рекомендации показывают ваши вкусы,
их можно закрасить.

Если вы нашли расхождение с официальным приложением, приложите два скриншота при одинаковом
размере окна: оригинал и RS.

### Критические ошибки

Если ошибка касается безопасности, **не открывайте публичный issue**. Это, например:

- токен уходит куда-то кроме `yandex.ru` и `yandex.net` или попадает в лог;
- обновлялка ставит файл, который не совпадает с релизом;
- другая программа или другой пользователь Windows может прочитать токен.

Напишите через [Security → Report a vulnerability](https://github.com/SpolzerMod/yamusic-rs/security/advisories/new).
Сообщение увидят только владельцы репозитория. Подробнее в [SECURITY.md](SECURITY.md).

Если после обновления приложение перестало запускаться, это тоже срочно, но писать можно
в обычный issue, в заголовке укажите версию. Пока ждёте исправления, предыдущую версию можно
скачать со страницы [релизов](https://github.com/SpolzerMod/yamusic-rs/releases).

### Прислать код

- Одна правка — один pull request. Крупное изменение лучше сначала обсудить в issue.
- Перед отправкой должны проходить `cargo clippy --release --all-targets -- -D warnings`
  и `cargo test --release`. То же самое запускает CI.
- Код и комментарии пишутся на русском, интерфейс обращается к пользователю на «вы».
- `ui/theme.slint` и `src/palette.rs` руками не правятся, они генерируются скриптами из `tools/`.
- Если сломался запрос после обновления Яндекса, обычно достаточно поправить `src/client.rs`
  или разбор ответа в `src/api.rs`.

## Для разработчиков

### Сборка

Нужны:
- Rust 1.92 или новее (`rustup update stable`, в Arch также пакет `rust`);
- для Linux-сборки — системные библиотеки: `alsa-lib`, `dbus`, `fontconfig`, `freetype2`,
  `libx11`, `libxcursor`, `libxi`, `libxkbcommon`, `libxkbcommon-x11`, `libxrandr`, `wayland`
  (одной командой: `sudo pacman -S --needed base-devel rust alsa-lib dbus fontconfig freetype2
  libx11 libxcursor libxi libxkbcommon libxkbcommon-x11 libxrandr wayland`);
- для сборки под Windows, как в оригинале, — Visual Studio Build Tools с компонентом
  «Разработка классических приложений на C++» (MSVC и Windows SDK берут `rc.exe` для значка).
  Форк под Windows не собирается и не проверяется.

```bash
git clone https://github.com/SpolzerMod/yamusic-rs
cd yamusic-rs
cargo build --release
```

Готовый файл: `target\release\yamusic-rs.exe`. Первая сборка занимает 5–10 минут, в основном
из-за Skia и LTO.

Если `skia-bindings` не может скачать готовые бинарники Skia (корпоративный прокси, ошибка curl),
скачайте архив для своей платформы с [rust-skia/skia-binaries](https://github.com/rust-skia/skia-binaries/releases)
и укажите путь в переменной окружения:

```bash
SKIA_BINARIES_URL=file://C:/путь/к/skia.tar.gz cargo build --release
```

Для отладки подойдёт `cargo run`: в debug-сборке лог дублируется в консоль.

### Как устроено

| Файл | Что внутри |
| --- | --- |
| `src/main.rs` | Точка входа: один экземпляр на пользователя, выбор рендерера Skia без GPU. |
| `src/gui.rs`, `src/gui/landing_ui.rs` | Связь интерфейса с данными: страницы, меню, настройки, обновления. |
| `src/api.rs` | Запросы к API: каталог, лайки, плейлисты, волна, стримы. |
| `src/client.rs` | Всё, что Яндекс может поменять: OAuth-клиент, ключи подписи, заголовки. Ломается — правим здесь. |
| `src/player.rs` | Аудиодвижок в своём потоке: очередь, предзагрузка, сессии волны, фидбек. |
| `src/landing.rs` | Страницы из серверных блоков («Для вас», «Концерты», «Книги и подкасты»). |
| `src/assets.rs`, `src/i18n.rs` | Шрифты, спрайт иконок и словари переводов из `app.asar` оригинала или с music.yandex.ru. |
| `src/images.rs`, `src/net.rs` | Фоновая загрузка обложек и данных страниц, кэши с бюджетом памяти. |
| `src/tray.rs`, `src/win.rs` | Трей, окна, автозапуск и прочий Win32. |
| `src/discord.rs` | Rich Presence через локальный канал Discord, без сторонних библиотек. |
| `src/update.rs` | Проверка релизов на GitHub и замена exe на лету. |
| `ui/theme.slint`, `src/palette.rs` | Сгенерированы `tools/gen_theme.py` и `tools/gen_palette.py` из CSS и JS оригинала. Руками не править. |

Приложение не перерисовывали на глаз. Цвета, размеры и отступы
сняты из CSS официального приложения скриптами в `tools/` (их запускают на распакованном
`app.asar`: `npx @electron/asar extract app.asar app`). Новые экраны сверяются с оригиналом:
его запускают с `--remote-debugging-port`, через DevTools Protocol снимают размеры DOM и скриншот
1280×800, а затем сравнивают с окном RS попиксельно.

Страницы собирает сервер, как у оригинала: `GET /landing/skeleton/<id>` возвращает список блоков
с типами и адресами данных, и каждый тип блока — свой компонент в `ui/landing.slint`. Неизвестные
типы пропускаются, поэтому новые блоки Яндекса не ломают страницу.

«Моя волна» работает через сессии ротора (`/rotor/session/new`, `/tracks`, `/feedback`), с настройками
из `/rotor/wave/last`. Пропуски и дослушанные треки уходят вместе со следующим запросом треков,
чтобы сервер подбирал продолжение уже с их учётом.

Шрифты, иконки и переводы не лежат в репозитории. `assets.rs` читает их из `app.asar`
установленного оригинала (WOFF переводится в sfnt на лету), а если оригинала нет, скачивает
с веб-версии. Словари ru/en/uz/kk — это чанки webpack оригинала, ключом служит русская строка.

### Релиз

Exe для релизов собирает GitHub Actions ([`.github/workflows/build.yml`](.github/workflows/build.yml))
из исходников тега. Лог сборки открыт, поэтому видно, из какого кода получился файл.

```bash
git tag v1.0.1          # версия должна совпадать с Cargo.toml
git push origin v1.0.1
```

Сборка прогоняет clippy и тесты, собирает `yamusic-rs.exe` и выкладывает его в релиз. На каждый
push и pull request exe тоже собирается, его можно скачать из артефактов сборки. Встроенная
обновлялка ищет в релизе файл с именем ровно `yamusic-rs.exe` и сверяет его с `digest`, который
GitHub считает при загрузке.

## English

**Yandex Music RS** is an unofficial Yandex Music client for Windows written in Rust. It mirrors the
official desktop app closely (same fonts, colours, layout and pages), but instead of
Electron it is a single 26 MB executable that renders its window on the CPU with Slint and Skia.
Running the same scenario, the official app uses about 850 MB of RAM across 7 processes, and RS
uses about 65 MB in one process.

- **Download** `yamusic-rs.exe` from the [latest release](https://github.com/SpolzerMod/yamusic-rs/releases/latest)
  and run it; there is no installer. Sign in with the code shown at [ya.ru/device](https://ya.ru/device).
  The app updates itself from GitHub releases.
- **Requirements:** Windows 11 (Windows 10 should work but is not tested regularly), a Yandex account,
  and Yandex Plus for full-length tracks. Linux builds are planned; macOS is not.
- **Privacy:** the token is encrypted with Windows DPAPI and only sent over HTTPS to `yandex.ru` /
  `yandex.net`. Besides Yandex, the app only talks to `api.github.com` (update checks) and the local
  Discord client (optional status). There is no telemetry.
- **Build:** Rust 1.92+, MSVC Build Tools with the Windows SDK, then `cargo build --release`.
- **Bugs:** open an [issue](https://github.com/SpolzerMod/yamusic-rs/issues/new/choose) with the app
  version, your Windows version and the last lines of `%APPDATA%\yamusic-rs\log.txt`. Security
  problems go to [Report a vulnerability](https://github.com/SpolzerMod/yamusic-rs/security/advisories/new),
  not to public issues.

under the same license. This project is not affiliated with or endorsed by Yandex. All trademarks
